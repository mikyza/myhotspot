Which download do i need?

  • Windows pack: a Windows PC runs the billing system. Good for trying it out, and for a MikroTik router

or a "popup test" with no real blocking.

  • Linux pack: an Ubuntu/Debian machine runs the billing system AND acts as the router (free, no MikroTik).

This is the best choice for speed and for real blocking.

  • MikroTik pack: you already own a MikroTik router. The billing system runs on a Windows PC or a Linux

server next to it and creates a hotspot user on the router for every paid customer.

Before you start (all packs)

a. Sign in on the website (or press "Start free trial") and open Connect hotspot. Copy your ISP id and API key.

b. Install the pack (sections 3, 4 or 5).

c. Open the admin page, paste the ISP id and API key on the activation screen and press Activate.

The program does nothing until your trial or subscription is active. When it ends the program locks (the website sends reminders by SMS first). Paying on the website unlocks it again within minutes. First admin password: admin123. Change it at once (Admin > Settings > Change admin password). Each pack ships with demo mode ON, so no real money is charged until you turn it off.

Windows pack

1. Unzip it. Double-click "Install or Update.bat" and press Yes. It starts by itself every time the PC switches on, in the background.

2. The admin page opens: http://localhost:8080/admin

3. Customers use http://<this-pc-ip>:8080/ . Give the PC a fixed IP address.

4. To update: unzip the newer pack and run "Install or Update.bat" again. Your settings and sales stay.

5. To remove: "Uninstall.bat".

Windows alone cannot block internet. To force customers to sign in you need a MikroTik router (section 5) or the Linux pack (section 4). "Popup test mode" (Settings) only lets you see the sign-in popup and payment screens.

Linux pack (the machine is the router)

You need Ubuntu or Debian with systemd, an internet line, and either a second network port plus a WiFi router in access-point mode, or a WiFi card that supports AP mode.

1. Install:

unzip hotspot-billing-linux.zip -d hb && cd hb && sudo bash install.sh

Admin page: http://<machine-ip>:8080/admin

2. Find your port names:

ip -br link

3. Router version (WiFi router in AP/bridge mode, DHCP off, cable in one of its LAN ports):

sudo bash gateway-setup.sh router --lan enx00e04c680001 --wan eth0

WiFi-card version (the machine's own WiFi card is the hotspot):

sudo bash gateway-setup.sh wifi --ssid "My WiFi" --wan eth0 --channel 6 --pass secret123

4. Admin > Settings > "Linux gateway": tick it and press "Save & apply gateway rules". Make sure MikroTik is off.

5. Customers get 10.0.0.10-254 and are sent to http://10.0.0.1/ until they pay or enter a code.

6. Switch it all off again: sudo bash gateway-undo.sh

Logs: journalctl -u hotspot-billing -f Data: /opt/hotspot-billing/ If speed is low run: sudo bash speed-doctor.sh If a customer has no internet run: sudo bash gateway-doctor.sh To update: unzip the new pack and run sudo bash install.sh again.

Mikrotik pack

The pack holds the billing system for Windows (windows folder) and for Linux (linux folder). Pick the one for the computer that will sit next to your router. It must stay on all the time and have a fixed IP address.

1. Install the billing system on that computer (section 3 for Windows, "sudo bash install.sh" in the linux folder for Linux). Open the admin page.

2. Admin > Router setup (MikroTik). Fill in the bridge name, the router IP, this computer's IP, the DHCP pool name and an API user and password. Press "Create router script".

3. In Winbox open New Terminal, paste the whole script and run it. Every LAN port and the WiFi interface must already be in the bridge you named (check with: /interface bridge port print). The script puts a hotspot on the bridge, allows one device per connect code, blocks sharing, opens the API for this program and lets customers reach the buy page before signing in.

4. Press "Download branded login.html" and upload that file to the router's hotspot folder (Files > hotspot).

5. Admin > Settings > MikroTik: tick "Create hotspot users on a MikroTik router", enter router IP, API port 8728, the API user and password, and press "Save & test router connection". It must say it connected.

6. Buy a package with your own phone to test, then turn demo mode off.

Speed limits: give a package a "Router profile" (for example 5mbps) that exists on the router. Data caps and per-package speed limits set in the package form work in the Linux gateway; on MikroTik use router profiles.

Settings you must fill in (admin > settings)

  • Business name, tagline, support phone / WhatsApp / email (shown to customers), admin phone (password reset).
  • PayHero: API username, password, channel id. Customers pay you directly. Leave "Public URL" empty.
  • Ping Africa SMS: URL and API key, then press "Auto-detect Ping Africa format" or "Save & send test SMS".
  • Packages: hotspot packages (connect codes) and monthly packages (normal WiFi accounts).
  • Turn OFF demo mode when you are ready for real money.

Daily use

  • Customer pays by M-Pesa on the sign-in page, gets a code by SMS and (in the Linux gateway) is connected at

once and sent to a page showing the code and the connection status.

  • Customer who lost the code: reconnect box (M-Pesa receipt or code). "Paid but no code": Admin > Recover.
  • Monthly customers: Admin > Accounts. Add the customer, they pay against their account number, their device

is remembered and connects without signing in.

  • Usage per client: Admin > Usage. Speed: Admin > Speed.

Extras (linux gateway)

  • Free TikTok: Settings > "Free TikTok trial". 15 minutes of TikTok only, once per device every 24 hours.

Works by TikTok's addresses, so a few shared addresses may open other sites. Needs dnsmasq 2.87 or newer for automatic address learning.

  • Anti-sharing: a connected customer cannot share the connection with other devices by phone hotspot.

Packages marked "Allow sharing" (router plans) are exempt, so one router can serve many people.

  • Backups: Admin > Cloud & license > Backups (daily automatic, plus an encrypted copy on the website).
  • Alerts: SMS to the admin phone when disk is full, PayHero keeps failing, the firewall is missing, etc.
  • Support: Admin > Cloud & license > Help > Send support info (no keys or passwords are sent).

Control it from the cloud (remote control)

Sign in on the website. ISP owners open Remote control; the software provider opens an ISP and its Remote control tab. Everything you change there is sent to the billing system and applied within about 20 seconds (the page says "Hotspot online"). If the hotspot is offline the change waits up to 7 days.

  • Settings: business and support details, demo mode, SMS text, free TikTok, MikroTik connection, alerts.
  • Packages: add, edit and delete packages (price, time, data cap, speed, sharing).
  • Buttons: re-apply router rules, test router, backup now, send support info, sync now, restart program.
  • Provider only: payment (PayHero) and SMS keys, the Linux gateway ports, the admin password. These are

write-only: they are never shown again after they are saved.

  • The provider can also edit an ISP's profile (business, email, phone, plan, valid until), suspend or extend it.
  • Customers' own records (codes, payments, monthly accounts) cannot be edited from the cloud.

The Recent commands list shows each change as Waiting, Running, Done or Failed with the reason. The hotspot only runs a fixed list of commands. There is no way to run anything else on the machine. The connection to the website itself (Cloud & license) can only be changed on the hotspot.

Problems

  • Cannot open the admin page: check the machine IP and port 8080; Linux: journalctl -u hotspot-billing -f
  • "Subscription ended": pay on the website; it unlocks within minutes. No contact with the website for more than

2 days after the paid-until date also locks the program.

  • Customers see a certificate warning on https sites before the sign-in page: unavoidable. Most phones open the

sign-in popup by themselves.

  • Payment taken but no code: Admin > Recover, or ask support.
  • A device that changes its WiFi address ("private address") may need to be re-linked by support.
  • Still stuck: Send support info (section 8) and contact the software provider.
